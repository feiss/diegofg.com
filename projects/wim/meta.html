I worked in the wim project for three and a half years, most of my time at Embark Studios. It was finally cancelled, but this project was very special, conceptually and technically:

Conceptually:

  • It was not a game, but a platform for players to create and play experiences.
  • There was no clear distinction between play and create. Everything (creation/modification and play) happened in realtime, in multiplayer.
  • Was meant to be first person mainly, and all user tools (for create or play) were fully diegetic, without 2D UI.

Technically:

  • Fully custom game engine made in Rust. No editor, no tools. Only Rust code.
  • NPCs created with SDFs and trained using machine learning for locomotion.
  • 3D assets modeled in Blender.

So this was a real challenge. Custom and very constrained engine, new API, new programming language, zero tools and a extremely challenging UX. The team had a very flat hierarchy where all ideas were heard and welcomed, and I was very proactive contributing to the game. More specifically, I was involved in these areas:

Art and Graphic Design:

  • Managed 3D artists artistically and technically
  • Created many 3D assets
  • Designed and modeled NPC characters
  • Created many concept art, storyboards, animatics for all kinds of aspects of the game.
  • Assisted my peers with any topic related to assets or vfx.
  • Designed the app icon
  • Designed merch (T-shirts, stickers, posters...)

UX Design and programming:

  • Responsible for the asset pipeline (conventions, scripting, Blender plugins...)
  • Designed and implemented the player customization system, with its in-game diegetic UX
  • Designed the idea, UX and implemented multiple in-game diegetic player tools:
    • The main coloring tool
    • Tools for scattering, arranging and spawning objects
    • Tool for freehand drawing in the world
    • Tools for animating objects in different ways (transformations, morph targets, gesture recording, presets, procedural, ...)
    • Tools for applying and editing logic and behaviors to objects
    • Added multiple selection support

Additional Programming:

  • Created the main particle system and implemented many effects like rain, snow, fireflies, confetti, fire, smoke...
  • Implemented Unity prototypes to quickly test relevant features before the team commited to them

 

It was not your typical technical artist role, as I also had the opportunity to get involved in many other areas. In particular, I was heavily involved in art direction and in the design and UX of in-game diegetic tools, focusing on ways to make creation and modification extremely simple and accessible while still allowing players plenty of room for self-expression.
