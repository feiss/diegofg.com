I worked in the wim project for three and a half years, most of my time at Embark Studios. This project was very special, conceptually and technically:

Conceptually:

  • It was not a game, but a platform for players to create and play experiences.
  • There was no clear distinction between play and create. Everything (creation/modification and play) happened in realtime, in multiplayer.
  • Was meant to be first person mainly, and all user tools (for create or play) were fully diegetic, no 2D UI.

Technically:

  • Fully custom game engine made in Rust. No editor, no tools. Only Rust code.
  • The engine had many strenghts, but also big limitations: No textures, no shaders, and very basic animation and skinning support.
  • NPCs created with SDFs and trained using machine learning for locomotion.
  • 3D assets modeled in Blender.

So this was a real challenge. Custom and very constrained engine, new API, new programming language (that I did not know), zero tools and a extremely challenging UX. The team had a very flat hierarchy where all ideas were heard and welcomed, and I was very proactive contributing to the game. I was involved in many different areas in this project:

  • I was responsible for the asset pipeline (conventions, scripting, Blender plugins...)
  • I created many 3D assets
  • Managed 3D artists artistically and technically
  • I designed the idea, UX and implemented multiple in-game diegetic player tools:
    • The main coloring tool
    • Tools for scattering, arranging and spawning objects
    • Tool for freehand drawing in the world
    • Tools for animating objects in different ways (transformations, morph targets, gesture recording, presets, procedural, ...)
    • Tools for applying and editing logic and behaviors to objects
    • Added multiple selection support
  • Created the main particle system and implemented many effects like rain, snow, fireflies,
    • confetti, fire, smoke...
  • Designed and implemented the player customization system, with its in-game diegetic UX
  • Designed and modeled NPC characters
  • Assisted my peers with any topic related to assets or vfx.
  • Created many concept art for tools, storyboards, and
  • Designed merch (T-shirts, stickers, posters...)
